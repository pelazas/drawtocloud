# DrawToCloud v1.1.0

**Release Date:** 2026-04-25

## Overview

v1.1.0 is a major stability and security release with 335 commits since v1.0.0. It introduces production-ready deployment infrastructure, significant security hardening, generation observability, and major canvas improvements.

---

## What's New

### Deployment & Infrastructure
- **Production Docker setup** — Dedicated `Dockerfile` and `docker-compose.prod.yml` with multi-stage builds
- **CI-based deploy workflow** — Images built and pushed to GHCR in CI, then pulled on the server (no more building on the server)
- **Health check gate** — Deploy waits for `/health/ready` before marking successful
- **Instant rollback** — Previous images are tagged as `:rollback` before deploy
- **WEB_CONCURRENCY enforcement** — Startup guards prevent multi-worker deployments that would break WebSocket delivery

### Security
- **CSP nonce** — Content Security Policy with per-request nonce via middleware
- **CORS restrictions** — Explicit allowlist for methods and headers
- **DOMPurify → sanitize-html** — SSR-safe HTML sanitization for Terraform viewer
- **BYOK encryption v2** — PBKDF2 key derivation, per-user salt, and key rotation support
- **LLM key validation** — `LLM_KEY_ENCRYPTION_SECRET` validated at startup
- **No localStorage credential storage** — ESLint rule blocks client-side API key storage
- **Rate limiting**
  - IP-based HTTP rate limit middleware
  - Per-user rate limits on expensive endpoints
  - WebSocket connection limits per IP and user

### Generation Observability
- **Live agent step panel** — Real-time visibility into Requirements → Architect → Cost Analyst pipeline
- **Agent milestone events** — Event-driven streaming of agent progress with timers
- **Architect repair & rerun** — Automatic retry with richer context on architect failures
- **Budget recovery** — Accept/Retry actions for budget-cap scenarios with state preservation

### Canvas & UX
- **Nested containers** — Recursive container layout with scope metadata (VPC → Subnets → AZs)
- **Manual node dragging** — Session-only manual positions with persistence
- **Bounded container resize** — `maxWidth`/`maxHeight` constraints via `NodeResizer`
- **Terraform outdated indicator** — Visual marker when canvas changes since last Terraform generation
- **Plan/Approve flow** — Chat-driven architecture changes require explicit plan approval before application
- **Chat UI refresh** — Timeline-based message layout with plan cards, budget recovery cards, and starter pills

### WebSocket Reliability
- **Heartbeat keepalive** — Prevents connection timeouts during long generations
- **Reconnect with stall recovery** — Automatic reconnection and generation stall detection
- **Graceful shutdown** — Lifespan hooks cleanly drain active tasks on SIGTERM

### Cost Estimation
- **Stateless cost estimate** — Template cost estimation via WebSocket without project creation
- **Fallback pricing** — Sensible defaults for unpriced/internal components (K8s, etc.)
- **Structural pricing exclusion** — Network containers (VPC, subnets) no longer priced as services

---

## Bug Fixes
- Empty architect streams now fail fast with clear diagnostics
- Coder rerun failures surface actionable error messages instead of opaque failures
- Canvas snapshot correctly merges Terraform files during active generation
- Template cost estimate responses are correlated with request ID to prevent stale data
- Chat errors are surfaced to the user instead of silently failing
- Generation footer copy removed to reduce UI clutter
- Budget retry preserves previous canvas state instead of wiping it

---

## Upgrade Notes
- Ensure `WEB_CONCURRENCY=1` is set in your deployment environment (enforced at startup)
- Ensure `LLM_KEY_ENCRYPTION_SECRET` is set and at least 32 bytes
- The deploy workflow now requires `packages: write` permission (already configured in repo settings)
